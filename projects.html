Comble (Phaser Game)

Comble is a fast-paced web game that my friend and I put together where you have to clear blocks before they stack too high. Sounds easy? Well, the speed keeps increasing, and before you know it, you're in full panic mode trying to keep up!

  • Gets harder as you go – Starts off chill but quickly turns chaotic.
  • Super easy to pick up – Just jump in and start playing.
  • No downloads, no installs – Runs straight in your browser.
  • Addictive gameplay – You’ll keep coming back to beat your best time.

We built Comble using JavaScript and Phaser.js, and the goal was to create a simple but addicting game that anyone could pick up and enjoy. The physics, speed increases, and mechanics were all tweaked to give the game a smooth but intense feel.

Autonomous Drones Project

This project focuses on developing a drone capable of autonomously navigating through randomly placed hoops using Rapidly-exploring Random Tree (RRT) path-planning algorithms. The goal is to generate an optimal flight path that allows the drone to traverse a sequence of hoops while minimizing overall distance traveled. A logarithmic loss function is used to adjust the path dynamically, exponentially reducing the error between test runs. The approach ensures that the drone efficiently adapts its navigation to pass through all hoops while optimizing for shortest path selection.

RRT Code Implementation


def drone_racing_rrt(start_pose: gtsam.Pose3, target_poses: List[gtsam.Pose3]) -> List[gtsam.Pose3]:
    '''
    Arguments:
     - start_pose: gtsam.Pose3, initial pose of the drone
     - target_poses: List[gtsam.Pose3], list of hoop poses (RRT targets)

    Returns:
     - drone_path: List[gtsam.Pose3], entire path from start to last hoop
    '''

    drone_path = []
    cStart = start_pose
    for t in target_poses:
        rrt, parents = run_rrt(
            cStart, t, generate_random_pose, steer, 
            helpers.distance_between_poses, find_nearest_pose, threshold=1.5
        )
        path = get_rrt_path(rrt, parents)
        helpers.pass_through_the_hoop(t, path)

        cStart = path[-1]
        drone_path += path
    return drone_path
